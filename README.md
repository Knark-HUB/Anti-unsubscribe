# «Жалоба, а не отписка» — MVP

Рабочий frontend-прототип и backend-заготовка SaaS-сервиса для Казахстана. Проект совместим с импортом GitHub-репозитория в **Bolt.new** и **Emergent**.

## Что уже реализовано

- адаптивный чат-интерфейс и голосовая кнопка;
- демонстрационная генерация и окно готового документа;
- прозрачная оценка полноты «Анти-отписка» без обещания результата;
- кабинет обращений, статусы и календарь контрольных дат;
- лист ожидания для выключенных стран;
- тарифы и мгновенная проверка промокода `START20`;
- каталог юристов;
- админ-панель с feature flags и купонами;
- светлая/тёмная тема и PWA manifest/service worker;
- схема Supabase с RLS;
- Edge Functions для генерации, расшифровки аудио и уведомлений;
- исправленное ТЗ и отдельные промпты для Bolt.new/Emergent.

## Локальный запуск

Требуется Node.js 22+ и pnpm.

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```

Для демонстрации ключи не нужны: интерфейс работает на тестовых данных. Для production подключите Supabase, примените SQL из `supabase/migrations`, разверните Edge Functions и заполните переменные окружения.

## Важные границы MVP

1. AI выдаёт **проект** документа, а не гарантирует принятие решения.
2. Оценка риска — показатель полноты и проверяемости, а не прогноз поведения госоргана.
3. Выбор маршрута «вышестоящий орган / прокуратура / суд» делается отдельным классификатором и требует подтверждения пользователя.
4. Срок хранится вместе с правовым основанием, типом дней, датой начала и продлением.
5. Нормативные ссылки берутся только из версионируемой базы официальных источников.

## Структура

- `app/` — интерфейс Next.js/Vinext;
- `supabase/migrations/` — схема данных и политики доступа;
- `supabase/functions/` — безопасные серверные AI-операции;
- `docs/TZ_REVIEW.md` — проверка исходного ТЗ и приоритеты MVP;
- `docs/BOLT_NEW_PROMPT.md` — инструкция для Bolt.new;
- `docs/EMERGENT_PROMPT.md` — инструкция для Emergent.

## Следующие production-шаги

- подключить Supabase Auth и заменить демо-данные запросами;
- загрузить и юридически проверить базу нормативных источников Казахстана;
- подключить OpenAI/Gemini только через серверные функции;
- определить первый реальный платёжный шлюз и фискализацию;
- подключить email/push и планировщик;
- провести privacy/security review до загрузки документов граждан.
